# PRD 01 · 分镜头 AI 画面替换（Shot-level AI Picture Replacement）

> 目标：Windows 版按本文档实现，达到与 macOS 版**逐控件对齐**。
> 参考实现：macOS SwiftUI 版本 v0.7.x。文中尺寸单位为**逻辑点(pt)**（≈ Windows 的 DIP），颜色/字号给出语义值 + 参照。
> 截图：`../screenshots/shot-edit.png`

---

## 0. 一句话定义

用户在「分镜素材库」对**某一条逻辑分镜**右键 →「分镜头替换」，打开一个**全屏弹窗工作区**：系统先把这条逻辑分镜按**画面变化度**切成若干「物理镜头」；用户可对镜头做**合并 / 拆分 / 移动边界**；对某个镜头输入**文字提示词**用 AI 生成"画面变体"；每个镜头位置**占位式选一个版本**（原版或某变体）；点「合成新分镜」把结果**就地替换**这条分镜的画面（可切回原画面、可恢复），**不新增分镜、不打乱后续排列组合**。

## 1. 入口与关系

- **入口**：分镜素材库里，每张分镜卡片的**右键菜单**第 3 项「分镜头替换」（不是顶部工具栏按钮）。菜单项顺序：复制台词 / 编辑台词 / **分镜头替换** / 删除替换画面 / 在 Finder 中显示原视频 / 删除分镜。
- **删除替换画面**：右键菜单里另有一项，用于把已合成的替换画面清掉、恢复为原画面。
- 打开后是一个 **modal sheet**（模态弹窗），覆盖主窗口。

- 弹窗最小尺寸：**宽 760 × 高 580**（可随窗口放大）。

## 3. [A] 顶栏（header）

容器：水平排列，四周 padding **12**。

| 元素 | 内容/样式 | 行为 |
|---|---|---|
| 标题 | 文本「分镜头替换」，字号 **headline**（≈17pt 粗） | — |
| 副标题 | 该分镜台词；无台词时显示「无台词」。字号 **caption**（≈12pt），次要灰色，**单行截断** | — |
| 弹簧 | 占据中间空白，把右侧按钮推到最右 | — |
| 合成按钮 | **主按钮**（borderedProminent，蓝底白字）。常态：图标`square.stack.3d.down.forward` + 文字「合成新分镜」。进行中：显示小号转圈 spinner | 点击 → 执行合成；成功后**自动关闭弹窗** |
| 关闭按钮 | 普通文字按钮「关闭」 | 关闭弹窗（不合成） |

**合成按钮禁用条件**（三者任一即灰）：① 不满足合成完整性（见 §7.4 `canCompose`）；② 正在合成中；③ 没有任何镜头。

## 4. [B] 分镜头轨道（ShotTrackRow）

区域上下留白 **12**。内部：一条**横向滚动**的镜头条（不显示滚动条），左右内边距 **16**；镜头卡与卡之间**没有间距**，取而代之的是"分界控件"。轨道下方是"选中镜头的编辑行"。

### 4.1 镜头卡（每个物理镜头一张）

- 顺序按 `orderIndex` 升序（1,2,3…）。
- **卡片宽 96**，从上到下：
  1. **视频预览**：`96 × 170`（**9:16 竖屏**，铁律）。默认显示该镜头**首帧缩略图**；**鼠标悬停自动播放**该镜头在源视频里的那一段 `[startFrame/fps, endFrame/fps]`，播放到末尾定格；移出停止。同一时刻**全工作区只有一个**在播（悬停另一张会切走）。播放器**无控件、画面填满**（等比裁切铺满，不留黑边）。
  2. **左上角标签**「镜头 N」：字号 caption2 加粗，白字，黑色半透明(0.5)胶囊底，内边距 横5纵2，距边 4。
  3. **选中描边**：选中时整个预览套一圈**强调色**圆角矩形边框（圆角 8，线宽 **2.5**）；未选中无边框。
  4. **时长**：`X.Xs`（一位小数），caption2 次要灰。
  5. **资格标签**（第三行）：
     - 可编辑镜头（2–10s）：已选了变体则显示「已选变体」（强调色）；否则「原版」（次要灰）。
     - 超限镜头（<2s 或 >10s）：显示「**超限·仅原版**」（橙色）。
- **点击卡片** → 选中该镜头（下方版本区随之切换到这个镜头）。

### 4.2 分界控件（相邻两镜头之间，boundaryControl）

容器宽 **28**，左右 padding 2，纵向两个元素（间距 6）：

1. **可拖动分界手柄**：圆角矩形(圆角3)，**强调色半透明(0.55)**，尺寸 **6 × 170**，中间叠一个左右箭头图标 `arrow.left.and.right`（8pt 白色）。
   - **拖动**：左右拖动改变这两个镜头的公共边界。灵敏度 **2pt ≈ 1 帧**（粗调；精调用下方 ±帧）。拖动时实时预览、**松手才落库**。边界被 clamp（见 §7.2），拖到底不会越界。
2. **合并按钮**：无边框图标按钮 `arrow.trianglehead.merge`（caption2），悬停提示「合并这两个镜头」。点击 → 把这两个镜头**合并成一个**（新镜头 = 左镜头起点到右镜头终点）。

### 4.3 选中镜头的编辑行（editRow）

仅当有选中镜头时出现，在轨道正下方，左内边距 16，水平排列（间距 10）：

- 文本「镜头 N 边界」（caption2 次要灰）。
- **左 / 右 微调器**（stepper）：调该镜头与相邻镜头的边界。
  - 非首镜头显示「左」微调器（调与上一镜头的边界）；非末镜头显示「右」微调器（调与下一镜头的边界）。中间镜头两个都显示；首镜头只有「右」；末镜头只有「左」。
  - 每个微调器 = 标签（「左」/「右」，caption2 更浅）+ `−` 按钮 + `+` 按钮（无边框小号）。**点一下 = ±1 帧**，立即落库。
- **拆分按钮**：bordered 小号，图标 `scissors` + 文字「拆分」。点击 → 把当前选中镜头**从正中间一分为二**。

## 5. [C] 版本区（ShotVariantPicker）

四周 padding **16**。仅当选中了某个镜头时显示；未选中时该区显示居中次要文字「选择上方一个分镜头来替换」。

### 5.1 标题
「镜头 N · 选一个版本用于合成」，字号 subheadline 加粗。

### 5.2 版本卡横向滚动条（卡间距 10）

**① 原版卡**（永远第一张）：
- 视频预览 `90 × 160`（9:16），悬停播该镜头源片段；选中（=当前坑选原版）时套强调色描边（圆角8，线宽2.5）。
- 下方「原版」（caption2）+ 时长 `X.Xs`（caption2 次要）。
- 点击 → 该镜头选定"原版"。

**② 变体卡**（按生成时间升序，每生成一个多一张）：预览 `90 × 160`，三种状态：
- **生成中**：黑色(0.85)圆角底 + 小号转圈 + 状态文字（如「生成中」，caption2 白色0.8）。
- **失败**：橙色警告三角 + 「失败」。
- **完成**：显示变体结果视频，悬停可播（0 到镜头时长）。
- 选中（该坑选了此变体）时套强调色描边。**点击（仅完成态可点）** → 该镜头选定此变体。
- 卡下方：
  - **提示词原文**（caption2，单行截断，宽 90）。
  - 完成态额外一行：`X.Xs · 同原长`（绿色 caption2）——强调变体时长与原镜头一致，让用户确认音画能对齐。
  - **删除按钮**（垃圾桶图标，无边框，destructive 红；生成中禁用）→ 删除该变体（连带落盘文件；若正被选中则回退为原版）。

### 5.3 提示词区（promptArea）——仅"可编辑镜头(2–10s)"显示

- 顶行：左「提示词」（caption 次要）+ 右「预设」下拉菜单（无边框）。
- **预设菜单**为二级菜单，分组与内容如下（点选即填入输入框）：
  - **换背景**：把背景换成明亮整洁的现代白色厨房，保持前景的手和产品完全不变 / 把背景换成夕阳下的海边沙滩 / 把画面背景里那幅画换成梵高的《星月夜》
  - **换主体外观 / 人物**：把画面里的长发女孩换成利落的短发 / 把手里拿的可乐换成一瓶雪碧，手的姿势和背景保持不变
  - **换颜色 / 材质**：把女孩的睡衣从粉色换成蓝色 / 把红色马克杯换成透明玻璃杯
  - **整体风格**：把整个画面调成清晨柔光、暖色调
- **输入框**：圆角边框，**多行**（1–3 行自适应），占位文字「例如：把手里的可乐换成一瓶雪碧，手和背景不变」。
- **生成变体按钮**：主按钮（borderedProminent），图标 `wand.and.stars` + 文字「生成变体」。**输入为空时禁用**。点击后：新建一张"生成中"变体卡、调用 AI、**清空输入框**。
- **说明文字**：「约 2~4 分钟生成，按次计费。同类替换（可乐↔雪碧、换背景、换颜色）效果最好。」（caption2 次要）。

**超限镜头**不显示提示词区，改为一行橙色说明（见 §7.1 文案）。

## 7. 规则与算法（后端/纯逻辑，Windows 必须一致）

### 7.1 分镜头切分规则（打开工作区首次进入时执行一次并落库）
1. 对源视频做**画面变化度（场景切换）检测**，阈值 **0.3**（FFmpeg 场景检测），得到一组"画面切换时间点"。
2. 只取落在本分镜时间窗口 `(segStart, segEnd)` **严格内部**的切点。
3. 从 `segStart` 起**贪心接受**切点：某切点被接受当且仅当它距上一个已接受边界 **≥ 0.5s** 且距 `segEnd` **≥ 0.5s**（保证每个镜头 ≥ 0.5s，避免碎片）。
4. 边界序列 = `[segStart] + 已接受切点 + [segEnd]`，相邻两点构成一个镜头，转成**源视频绝对帧号区间**，`orderIndex` 从 1 递增。
5. 切不出（分镜过短/无切换）→ 整条分镜就是 1 个镜头；若连 1 个都无法生成，工作区显示「未能切出分镜头（该分镜可能过短或无画面切换）」。
- **已切过的分镜**再次打开直接用上次结果（持久化），不重切。

### 7.2 切分不变式（铁律，任何编辑后都必须成立）
- 所有镜头按 orderIndex 升序、**首尾无缝铺满** `[segment.startFrame, segment.endFrame]`：
  - `镜头1.start == 分镜.start`；`镜头i.end == 镜头(i+1).start`；`末镜头.end == 分镜.end`。
- **所有镜头时长之和 ≡ 分镜时长**。合并/拆分/移动边界都不能破坏它（用"切分点建模"实现：编辑的是 N−1 个切分点，段落自动跟随，结构上不可能出现空隙/重叠/总长不符）。

### 7.3 编辑操作的边界条件
- **最小帧数 = 5 帧**：移动边界会被 clamp 到 `[左镜头start+5, 右镜头end−5]`；拆分点必须落在 `[start+5, end−5]`，否则该操作无效（原样返回）。
- **合并** i 与 i+1：新镜头 = `[镜头i.start, 镜头(i+1).end]`。
- **拆分**（UI 用中点）：在 `(start+end)/2` 处一分为二。
- **改动会波及的镜头**（被合并/拆分/移动了边界的镜头）：其**已生成变体全部失效删除**（连带落盘文件）、选择回退原版、缩略图重生成；未被动到的镜头保留其变体。**同时作废整条分镜已合成的"替换画面"**（防止导出用到过时画面）。

### 7.4 可编辑性与合成完整性
- **可编辑区间**：镜头时长 ∈ **[2s, 10s]** 才能生成 AI 变体。
  - `>10s` 文案：「该分镜头 X.Xs 超过 10s 上限，请用帧级调整拆短后再替换」。
  - `<2s` 文案：「该分镜头 X.Xs 不足 2s 下限，无法替换」。
- **合成完整性 `canCompose`**：镜头数 >0，且 **1..N 每个镜头位置都必须有一个选择**（原版或某个已完成变体），否则「合成新分镜」禁用；强行合成会提示「每个分镜头位置都要选一个版本」。

### 7.5 AI 生成（变体）
- 模型：阿里 DashScope **wan2.7-videoedit**（异步任务：提交→轮询→下载）。
- **纯提示词**：不框选、不传参考图。
- **进多少秒 = 出多少秒**：变体时长严格等于该镜头时长，零帧漂移（故 UI 标「同原长」）。
- 耗时约 **2~4 分钟**，**按次计费**。同类替换（可乐↔雪碧、换背景、换颜色）效果最好；形状/动作差异过大易形变穿帮。
- 失败 → 变体标"失败"，把可读错误（翻译后的 API 错误码 + 原文）显示在错误横幅。

### 7.6 合成 + 就地替换
- 合成 = 按 orderIndex 顺序，把每个镜头位置**选定的版本**（原版 = 从源视频切该镜头帧区间；变体 = 用变体结果片）拼接，并**复用原分镜的音频**混流成一条 MP4；分辨率 `720:1280`。
- 结果**就地写回原分镜**（不新增 Segment/Video）：存到"替换画面"字段（视频路径 + 缩略图 + 实际帧数），并把该分镜标记为"当前显示替换画面"。
- 分镜库/预览/导出统一通过 `Segment.effectivePicture` 单一真源取画面：`pictureShowsReplaced == true 且替换文件存在` → 用替换画面（0..帧数）；否则用原视频切片。
- 合成成功后弹窗自动关闭。分镜卡上出现「切换画面」小胶囊，可在**原画面 ↔ 替换画面**间来回切（可恢复）；右键「删除替换画面」彻底还原。
- **占位选择持久化**：每个镜头选了哪个版本存在 `PhysicalShot.selectedVariantID`，重开工作区仍保持。

## 8. 数据模型（供 Windows 建等价结构）

- **PhysicalShot**（物理镜头）：`id`、`parentSegment`（所属逻辑分镜）、`orderIndex`、`startFrame`/`endFrame`（源视频绝对帧）、`selectedVariantID?`（占位选中的变体）、`thumbnailPath?`、`variants`（1 对多，级联删除）；`frameCount = endFrame − startFrame`。
- **ShotVariant**（画面变体）：`id`、`shot`（所属镜头）、`prompt`、`status`（pending/uploading/generating/completed/failed）、`taskId?`、`resultVideoPath?`、`thumbnailPath?`、`friendlyError?`、`createdAt`。
- **Segment 新增"替换画面"字段**：`replacedPictureVideoPath?`、`replacedPictureThumbnailPath?`、`replacedPictureFrameCount`、`pictureShowsReplaced`（Bool）。派生 `effectivePicture`（原/替换单一真源）。改分镜帧范围或调整镜头 → `invalidateReplacedPicture()` 清空这四个字段。

## 9. 交互流程（Happy Path）

1. 分镜库右键某分镜 →「分镜头替换」→ 弹窗打开，显示「正在切分镜头…」→ 切出镜头 1..N，默认选中镜头 1。
2. 悬停各镜头预览确认切得对不对；需要就合并/拆分/±帧调边界（总长始终不变）。
3. 选中一个 2–10s 的镜头 → 在版本区输入提示词（或选预设）→「生成变体」→ 2~4 分钟后出变体卡。可对多个镜头各生成一个或多个变体。
4. 每个镜头位置**点选一个版本**（原版或某完成变体）——1..N 都选满，「合成新分镜」才可点。
5. 点「合成新分镜」→ 合成 + 就地替换 → 弹窗关闭。分镜库该分镜画面变为替换版，可用「切换画面」切回原画面。

## 10. 边界/异常清单（Windows 需覆盖）

- 分镜过短/无画面切换 → 只有 1 个镜头或提示切不出。
- 镜头 <2s 或 >10s → 不能生成变体，显示对应橙色文案；但仍可作为"原版"参与合成。
- 生成失败 → 变体标失败 + 底部错误横幅显示真实原因。
- 调整过的镜头 → 其旧变体自动清除、整条分镜替换画面作废。
- 未选满所有镜头位置 → 合成按钮禁用。
- 合成后再进工作区调整 → 替换画面作废，需重新合成。
