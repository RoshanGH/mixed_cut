# PRD 02 · 配音变体池 + 「参与排列组合」勾选

> 目标：Windows 版逐控件对齐 macOS 版 v0.7.x。尺寸单位为逻辑点(pt)。
> 截图：`../screenshots/dub-inspector-annotated.png`

---

## 0. 一句话定义

在「分镜素材库」**点选一条分镜**，右侧滑出「**配音变体池**」检视栏（宽 340）：这里管理该分镜的**改写版台词 + 配音**，并通过**「参与组合」勾选**精确控制——**勾了谁，谁才进导出的排列组合**（避免变体一多导出条数爆炸）。核心机关是：每个改写版一个「参与组合」多选框 + 一个固定的「原版参与组合」多选框 +「参与 N 档」实时计数。

## 1. 面板整体

- **宽度固定 340**，贴在分镜库右侧（与卡片网格之间一条分隔线）。背景 = 窗口背景色。
- **出现时机**：在分镜库**非多选模式**下**单击任意一张分镜卡片**（点卡片空白处），即把该分镜设为"当前选中"，右侧滑出本面板；点另一张切换到另一分镜。多选模式下点卡片是勾选，不出面板。
- 从上到下：**头部**（标题 + 分镜信息 + 原版参与组合行）→ 分隔线 → **内容**（重新改写条 + 各改写版卡片 + 手动添加按钮），内容超高可纵向滚动。

## 2. 各控件精确规格

### 2.1 头部（padding 14）
- 标题行：波形图标 `waveform.circle.fill`（tint 色，title3）+「配音变体池」（headline）。
- 分镜信息：「分镜 #{编号} · 时长 {X.X}s」（caption 次要）。
- **原版参与组合行**（仅非锁定分镜显示，顶部 padding 2）：
  - 左：多选框 + 「原版参与组合」（caption2）。绑定 `Segment.originalParticipatesInCombination`，勾选即存库。悬停提示「勾选后原版参与导出排列组合；与各改写版的「参与组合」共同决定组合数」。
  - 右：「参与 {N} 档」（caption2 次要），N = `combinationSlotCount`（§3）。

### 2.2 重新改写条（rewriteBar）
- 圆角 8 浅底卡（padding 10）。
- 忙碌时：小转圈 + 进度文字。空闲时：`arrow.triangle.2.circlepath` 图标 +「重新改写本分镜」（bordered small）。
- 下方说明：「改了原台词后，点此用新原文重写本分镜」（caption2 更浅）。

### 2.3 改写版卡片（versionCard，每个改写版一张；padding 12，圆角 10，浅底 + 0.5 描边）
- **顶行**（HStack spacing 6）：
  - 「改写版 {A/B/…}」徽章（caption 粗，白字，强调色胶囊，内边距 横8纵3）。
  - **字数提示**（见图例 7）。
  - **「参与组合」多选框**（见图例 8）：仅 `effectiveDub(该版)` 存在（已生成音频）时显示；绑定 `SegmentDub.participatesInCombination`；`isVoiceLocked` 时禁用并提示「已锁原声，不参与组合」。
  - 弹簧 → 右侧操作：非编辑态显示 铅笔(编辑) + 垃圾桶(删除，红)；编辑态显示 ✕(取消) + ✓(绿，保存并重新配音)。忙碌时隐藏编辑/删除。
- **正文**：非编辑态 = 台词文本（callout，可选中）；编辑态 = 多行输入框 `TextEditor`（高 80，强调色描边，⌘↩ 保存）。
- **配音时长警告**（生成后，仅两种）：字数比原片多很多 → 红「配音已大幅加速，建议精简」；配音比画面短 >0.5s → 橙「末尾留白，建议加字」。
- **音色格**（HStack，每个选定音色一格；格高 64，圆角 8 浅底）：
  - 顶部音色名（原声克隆显示「原声克隆」）。
  - 未生成：「生成」按钮（mini，`waveform`）。生成中：小转圈。已生成：▶/⏹ 试听（红/橙/绿）+ ↻ 重新生成（过期橙+感叹号）+ 时长（贴合绿 / 偏差橙，9pt 等宽）。

### 2.4 手动添加按钮
「＋ 手动添加一版（自己写台词）」（bordered small，`plus.circle`）；忙碌时隐藏。

## 3. 「参与排列组合」规则（★核心，Windows 必须一致）

**导出的一刻才组合**：一条分镜实际参与导出的"版本集合"按下式算，**没勾的（原版或变体）导出时就没有它**。此规则**对所有导出路径统一生效**——混剪方案的笛卡尔积导出 **和** 单分镜/批量分镜导出都遵循同一套。

对某分镜，其"参与集合"：
1. 若 `isVoiceLocked == true` → 恒为**仅原版（×1）**，忽略下述所有勾选（最高优先级）。
2. 否则 = `(原版 if originalParticipatesInCombination) ∪ (participatesInCombination==true 的各改写版)`。
3. **兜底**：若上述集合为空（原版没勾、也没勾任何变体）→ **回退为仅原版（×1）**，保证分镜始终在结果里、不断档。

**档数公式**（UI「参与 N 档」= 此值）：
```
combinationSlotCount =
    isVoiceLocked ? 1
                  : max(1, (originalParticipatesInCombination ? 1 : 0) + 勾选参与的改写版数)
```
**导出组合总数 = 各分镜 combinationSlotCount 连乘。**

**默认值**：原版默认**参与**（true）；新生成的改写版默认**不参与**（false，opt-in）。→ 分镜默认只出原版（×1），不炸；用户手动勾想要的变体才进组合。

**作用范围（全局）**：勾选状态存在共享的 `Segment` / `SegmentDub` 上，对所有用到该分镜的方案统一生效。

---

## 4. 空态与边界

- **锁定原声的分镜**（明星出镜）：面板内容为居中锁图标 +「保留原声（明星出镜锁定，不参与配音）」（橙）；头部不显示"原版参与组合"行；恒 1 档。
- **还没有任何配音**：居中提示「点顶部『一键改写台词』自动克隆原声并生成配音 / 或在下方手动添加一版自己写台词」+ 手动添加按钮。
- 未生成音频的改写版：**不显示**「参与组合」多选框（无音频不进组合）。
- 全不勾（原版 + 所有变体都没勾）：该分镜仍出原版、方案不断档（兜底 ≥1 档）。

---

## 5. 数据模型（Windows 建等价字段）

- `SegmentDub` 新增：`participatesInCombination: Bool = false`（该改写版是否参与组合）。
- `Segment` 新增：`originalParticipatesInCombination: Bool = true`（原版是否参与组合）。
- 派生：`combinationDubVariants` = 已生成且勾选参与的改写版；`combinationSlotCount` = §3 公式（单一真源，UI 与导出共用）。
- 不改动"每槽单选下拉"（方案里每个分镜单条预览用的选择）与 `effectiveDubVariants`（仍返回全部已生成变体，供面板展示）。
